# My Table — Beta

Première version partageable pour recueillir les retours d'amis.

Contenu :
- 285 adresses personnelles
- filtres personnels / guides / 2+ guides / 3+ guides
- recherche par nom, ville et tags
- carte Leaflet
- liens Google Maps et sources officielles
- croisements vérifiés avec OAD, Gault&Millau, Le Fooding et Michelin

Cette bêta sert à valider l'expérience utilisateur avant l'import exhaustif des univers de guides.
